# Phase 13 backend validation

The offline Taiwan Typhoon end-to-end test executes the supported backend chain with the Nova Electronics data: mock weather signal, supplier-site entity match, incident context, BOM and impact traversal, risk scoring, OR-Tools mitigation optimization, recommendation, approval routing, idempotent mock execution, and predicted-versus-actual verification.

The test is intentionally frontend-independent and uses no external provider or credentials.
